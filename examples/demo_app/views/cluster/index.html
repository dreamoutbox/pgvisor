How PgVisor Routes Traffic
Read Query (SELECT) Standby Replica

PgVisor inspects incoming SQL statements. Pure reads route to healthy standby replicas to offload read traffic.

Write Query (INSERT / UPDATE) Raft Leader Primary

Data modifications and transactions route exclusively to the Raft-elected leader to ensure linearizable consistency.

Failover Connection Buffering

During failover elections, PgVisor buffers client queries instead of immediately dropping TCP connections.
